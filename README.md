# CodeSense AI 🤖

AI-powered code reviewer that analyzes code and provides suggestions for improvement.

## Features

- Review code using AI
- Supports multiple languages:
  - C++
  - C
  - Java
  - Python
  - JavaScript
- Finds bugs and suggests improvements

## Tech Stack

Frontend:
- React.js
- Bootstrap

Backend:
- Node.js
- Express.js

AI:
- Groq API

## How to Run

### Frontend

```bash
cd client
npm install
npm run dev


### Backend

```bash
cd server
npm install
node app.js
